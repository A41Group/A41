# A41 — Neighbourhood Market

Standalone static website. No build, backend, portal connection, or JavaScript required.

## GitHub Pages

Upload index.html, styles.css, and .nojekyll to the root of your dedicated website repository. In repository Settings → Pages, choose Deploy from a branch, select your branch and / (root), then Save.

## Editing

Edit the page copy and milestone in index.html. The interest count is manually maintained (currently 3 of 20); update the visible count, percentage, aria-valuenow, and the progress width in styles.css together. Images are intentionally placeholders. Replace each .photo container with your image when ready. Google Fonts supplies the typography with local fallback fonts if unavailable.

Community registration details are marked as forthcoming. No registration or WhatsApp connections are included.
